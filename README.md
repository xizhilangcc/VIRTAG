# VIRTAG

VIRTAG: a comprehensive classification tool for viral meta-omic data enriched with viral "dark matter"

## Installation
We recommend you to install all the package with Anaconda.
After cloning this respository, you can use anaconda to install the **webserver.yml**. This will install all packages you need with gpu mode (make sure you have installed cuda on your system).
We recommend you to install all the package with Anaconda.The command that you need to run is 
```bash
conda env create -f webserver.yml -n VIRTAG
```

## Usages

### Preparation of database utilized by VIRTAG

1. Download the desired version of the ICTV virus taxonomy database from the official website: https://ictv.global/vmr, and save it as a CSV file (e.g., ICTV_2024.csv).

2. Use the script database/preprocess_csv_file.py to extract entries from the virus taxonomy database at a specified taxonomic level (such as Family) and generate the file database/accession.txt.

```bash
python database/preprocess_csv_file.py \
    --database_csv_file ./database/ICTV_2024.csv \
    --level Family \
    --limited_count 8
```

3. Use the accession numbers obtained in database/accession.txt, go to the NCBI Batch Entrez page: https://www.ncbi.nlm.nih.gov/sites/batchentrez. Upload the accession.txt file to Batch Entrez to download the corresponding nucleotide or protein sequences in FASTA format.After the download is complete, rename the downloaded FASTA file to: database.fasta.

4. Use the script database/preprocess_sequences.py to preprocess the downloaded database/database.fasta file.
```bash
python database/preprocess_csv_file.py \
    --level Family
```

If you want to use the existing dataset, you can download it from the following link: https://drive.google.com/file/d/1Nf64h5cljlOqUuh5uNJRRZ1DVEjt7Hus/view?usp=sharing, and place it under the database directory. This database was created based on ICTV 2024 database at the family level, including only taxa that contain 8 or more members.

If you want to classify viral genomes at the genus or species level, you can build genus- and species-level databases in the same way.

### Perform taxonomic assignments

1.  use the script run_speed_up.py to classify viral genomes.

```bash
python run_speed_up.py \
    --contigs ./contigs.fasta \
    --database_path ./database \
    --class_counter_path ./database/class_counter.pkl
```

2. Extract the query contigs that have not been aligned or linked to the reference genomes.

```bash
python run_extract_unknow_contigs.py \
    ----contigs ./contigs.fasta
```

3. Cluster the sequences extracted in the previous step to identify unknown taxa.

```bash
python run_speed_up_unknow.py \
    --contigs ./contigs.fasta
```

### The result generated by VIRTAG

There are two result files in total: result/pred/prediction.csv and result_unknow/isolated_test_nodes_fixed_pc.txt.
The file prediction.csv contains the contig names and their corresponding prediction results, while isolated_test_nodes_fixed_pc.txt lists potential unknown taxonomic units.
